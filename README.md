## Tecnología

- Vite + React + TypeScript
- Tailwind CSS v4
- Desplegado en GitHub Pages

## Desarrollo

```bash
npm install
npm run dev
```

## Construcción

```bash
npm run build
```

El build genera la carpeta `dist/` configurada para GitHub Pages con base path `/my-sushi-to-go/`.

## Despliegue

El sitio se despliega automáticamente a GitHub Pages cuando se hace push a la rama `main`. La ruta base es `/my-sushi-to-go/`.
